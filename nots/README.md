## 长期有效的约定

- 仓库范围：LLM 参与可执行算法、启发式或求解程序的设计和改进；arXiv 预印本可以收录。无配套论文的软件不能充作论文。
- 相关性按方法内容判断；引用 EoH 可以作为检索线索，但引用本身不足以证明范围相符。不得仅凭名称相似收录。
- 论文讲解必须基于原文，解释设计对象、LLM 的作用、反馈及实验；不得复制摘要代替核心方法，也不能出现缺摘要之类占位内容。
- 文件夹用短、稳定 ID；显示缩写优先采用作者命名，否则使用清楚的关键词。
- 机构按原论文作者署名核实，引用 `data/institutions.yml` 的受控 ID；不能根据邮箱或作者现职猜测。
- 网站日期显示到月。正式发表/录用时间和 arXiv 首次提交时间需区分；版本修订不算新论文。
- relations 必须有方法内容依据，不能为凑数量、消除孤岛或构造环硬加。用户已取消每篇至多两条的限制；baseline 比较本身不构成关系。type/dimension 使用受控词表。
- AEL 与 FunSearch 按同期工作处理；不要擅自添加 EoH—FunSearch 关系。
- README 论文表与 `src/generated/content.json` 自动生成，不手工改生成区域。
- 修改通过分支和 PR 审核，用户决定是否 merge；已有未合并 PR 时继续同一个 PR。保留旧修复分支中的工作，不擅自删除。
- 拉取前检查脏工作区和分支状态，保留用户编辑；本地报告不等于已提交或已发布。
