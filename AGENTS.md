# Project continuity

Before working in this repository, read `nots/README.md` and the latest relevant
dated note in `nots/`. The user requested this directory for persistent project
decisions and progress. Update the relevant note before handing work back.

Keep research candidates separate from published paper entries until the user
selects them. Follow the review and curation rules recorded in `nots/README.md`.

## Local-only working records

Discussion notes, candidate lists, previews and implementation plans belong in
the ignored `nots/`, `plans/` or `docs/plans/` directories. Keep these files on
the local machine. Never commit, force-add or upload them. Do not delete them
while cleaning the repository. If local continuity notes are absent in a fresh
clone, record new decisions locally without inventing previous decisions.

Public documentation and production assets stay tracked. Do not link public
documentation or code comments to local-only records.
